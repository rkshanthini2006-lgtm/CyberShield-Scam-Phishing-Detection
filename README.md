# 🛡️ CyberShield – Scam & Phishing Detection System

## 📌 Project Overview
CyberShield is a web-based application that helps users identify phishing URLs, scam messages, and suspicious emails using Python-based analysis and a PHP web application.

## 🚀 Features
- URL Scam Detection
- Email Phishing Detection
- SMS Scam Detection
- Risk Score Analysis
- Scan History
- User Authentication
- Dashboard
- Reports
- Power BI Analytics

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- Python
- MySQL
- Git & GitHub
- Power BI

## 📂 Project Structure

Frontend → User Interface

Backend → PHP APIs

Python → Scam Detection Engine

Database → MySQL Database

Power BI → Dashboard Reports
